Something not working, or an idea for a new feature? We're happy to help.

<Steps>

1. **Check the FAQ** of your plugin, for example the [Energy Prices NL FAQ](../energy-prices/faq/).

2. **Open an issue** on [GitHub](https://github.com/brightforge-bv/brightforge-plugins/issues/new). You need a free GitHub account.
   Please include:
   - the plugin name and version (Stream Deck app → *Preferences* → *Plugins*)
   - your Stream Deck model, and macOS or Windows
   - what you expected and what happened, a screenshot helps

</Steps>

<Aside type="tip" title="Log files">
If we ask for a log file, you find it in the plugin's `logs` folder:

- **Mac:** `~/Library/Application Support/com.elgato.StreamDeck/Plugins/com.brightforge.energyprices.sdPlugin/logs`
- **Windows:** `%appdata%\Elgato\StreamDeck\Plugins\com.brightforge.energyprices.sdPlugin\logs`
</Aside>
